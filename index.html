ER/Inpatient delay alerts

A SCHEDULED or Asked-to-send ER/Inpatient order that's sat without action longer than these thresholds gets flagged on the worklist — orange first, red once further overdue — so it stands out as needing attention. The clock resets whenever a tech acts on it (asks to send, or sets/changes a delay reason).

Choose which studies show up on the order form. The left list controls what's available overall (to radiologists, and to technologists for outpatient orders); the right list is the smaller subset a technologist may pick from when creating an ER/Inpatient order themselves — it's automatically limited to whatever is checked on the left.

Add custom protocol

Add a new named protocol to the catalog — separate from the "Other / custom protocol" free-text option staff can already type per order. Once added, it behaves like any built-in protocol: enable/disable it below, allow technologists to use it for ER/Inpatient, and rename it later if needed.

Completed orders retention

Controls how long a Done order is kept before being permanently removed. Admin > Stats needs a completed order to still exist to count it, so keep this at least as long as you want monthly stats history for.

Deleted orders retention

Controls how long a soft-deleted order (deleted by staff, or auto-removed for sitting unresolved) stays recoverable below before being permanently removed.

No-show retention

Controls how long a patient stays in the "🚫 No-shows" reminder list on the worklist before being permanently removed.

X-ray queue retention

Controls how long a finished X-ray queue entry is kept before being permanently removed. Waiting entries are never auto-purged, only finished ones.
